# ProxyKit desktop UI

Run `npm install` and `npm run tauri dev` from this folder. The app opens PNG, JPEG, and WebP images, launches the local Windows watermark or printed-card-text research workflow when available, compares the output with the source, and exports a copy.

The app's frontend is TypeScript and its native commands are Rust. The existing Python workflows are external research dependencies in `../research/`, not part of the packaged application. **Remove card text** automatically detects high-confidence horizontal text, with an optional vertical scan, and uses local FLUX.2 Klein to repaint complex regions. Text over smooth card graphics is filled from nearby clean pixels. It writes `*_text_removed.png` beside the input, preserving the source. If you select a `*_text_highlighted.png` detection preview as the source, the app opens its unmarked original from the accompanying JSON. This experimental result can alter card artwork within the detected regions and will leave text the detector misses. Compact emblems and detailed power areas are preserved when their backgrounds cannot be safely reconstructed. See the [project README](../README.md), [watermark research report](../research/REPORT.md), and [text-removal research](../research/TEXT_REMOVAL_RESEARCH.md).

**Extract card effects** runs local OCR and shows an editable transcription. Choose Japanese or French, then use **Translate to English locally**. Recognized Japanese rule phrases are parsed locally; unfamiliar phrases and French text use the local Qwen3-1.7B model. The app shows a separate editable English draft. Both OCR and translation JSON files are saved beside the input image. The translation step does not send card text or images to a cloud service. It flags some missing numbers, limits, and terms, but these checks are incomplete; verify every effect against the card before relying on it. The current research runtime is Windows-only and needs `../research/models/qwen3-1.7b/`, populated by `../research/setup_qwen_translation_model.py`. The model is from [Qwen/Qwen3-1.7B](https://huggingface.co/Qwen/Qwen3-1.7B).
